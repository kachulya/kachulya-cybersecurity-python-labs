## Предметна область
Сервіс обліку тривалості перевірки повідомлень про події безпеки:
- **Категорії (`categories`)**: джерело повідомлення (`siem`, `helpdesk`, `monitoring`).
- **Поле `value`**: тривалість перевірки у хвилинах (`unit = minutes`, `float >= 0`).
- **Поріг реагування**: `15.0` хв.
- **Статуси (`status`)**: `new`, `in_progress`, `done`.
